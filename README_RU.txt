NEXUS ISLAND 1.0 — Windows 10/11 x64
====================================

СБОРКА ЧЕРЕЗ GITHUB ACTIONS (локальный .NET SDK не нужен)
1. Распакуйте архив.
2. Замените файлы в корне своего репозитория этими файлами. Папку .github тоже замените.
3. Отправьте изменения в ветку main или master.
4. Откройте GitHub → Actions → Build NEXUS ISLAND.
5. Дождитесь зелёного статуса, откройте завершённый запуск и скачайте artifact
   NEXUS-ISLAND-1.0-win-x64.
6. Распакуйте artifact и запустите NEXUS_ISLAND.exe.

ЧТО РЕАЛЬНО РАБОТАЕТ В ЭТОЙ СБОРКЕ
- Компактный остров закреплён по центру верхнего края экрана.
- Часы, день недели и дата обновляются автоматически.
- Определяется раскладка клавиатуры активного окна (RU/EN).
- Кнопка раскрытия/сворачивания и плавная анимация панели.
- Наведение на основную часть компактной капсулы включает прозрачность и пропуск кликов;
  зона кнопки раскрытия остаётся интерактивной.
- Системная панель показывает загрузку CPU, использование RAM, батарею,
  версию Windows, имя ПК и архитектуру.
- Быстрые заметки сохраняются локально в %AppData%\NexusIsland\note.txt.

ЧЕГО ПОКА НЕТ
Музыкальная интеграция Windows Media Sessions, системные уведомления всех приложений,
синхронизация Android/Phone Link, погода из интернета, конструктор пользовательских
виджетов, история буфера обмена, полка загрузок, календарная синхронизация,
автозапуск и автообновление. Эти функции не имитируются фиктивными данными.

ТЕХНИЧЕСКИ
WPF / C# / .NET 10, Windows API, self-contained single-file win-x64.
Проверка компиляции должна выполняться в GitHub Actions на Windows runner.
В текущей среде Windows/.NET SDK нет, поэтому готовый EXE здесь не собран.
