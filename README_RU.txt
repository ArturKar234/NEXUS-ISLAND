NEXUS ISLAND — Windows 11 x64

В этой сборке:
- постоянная верхняя центральная капсула;
- часы, RU/EN по раскладке активного окна, день недели и дата;
- поверх остальных окон;
- сквозной режим: при наведении полупрозрачность 38%, клики проходят к окну под островом;
- Ctrl+Alt+I переключает сквозной режим; в режиме управления наведение раскрывает панель;
- панель содержит переключатель режима и выход.

Это первая оболочка. Музыка, уведомления, батарея, погода, загрузки, буфер обмена,
конструктор, GPU, телефонная связь и автозапуск ещё не реализованы.
Центрирование выполняется относительно основного монитора.

КАК ПОЛУЧИТЬ EXE:
1. Загрузить всё содержимое архива в корень GitHub-репозитория, включая .github.
2. Commit changes в ветку main.
3. Открыть Actions и дождаться зелёной галочки Build NEXUS ISLAND - Windows x64.
4. Открыть успешный запуск, скачать NEXUS_ISLAND-Windows-x64 в Artifacts.
5. Распаковать архив — внутри NEXUS_ISLAND.exe.
